## Selected work

**Quantum Neural Network for Hydrocarbon Exploration**
Quantum-inspired ML model applied to geological/geospatial data to improve hydrocarbon detection — a good example of taking AI outside the standard tabular-data use case.

**NDVI Analysis from Landsat Imagery**
Automated NDVI computation pipeline over satellite imagery for environmental monitoring, built with Python and standard GIS tooling.

**Smart Pathfinding & Map Visualization**
Dijkstra's algorithm applied to a real-world map of Tunisia, with an interactive Leaflet front end — graph theory meets geospatial data.

**Full-stack web & mobile platforms**
Multiple production React / React Native applications with authenticated APIs, cloud deployment, and CI/CD I set up and maintain myself.
